# Pindou 手动运行目标选择

当前启用的是独立仓库 `li-jingxuan/pindou`，Woodpecker 仓库 ID 为 `4`，分支 `main`；旧的 `liuxianmao/openchamber/pindou` 不再是本次配置目标。

## 使用方式

在 Woodpecker 的 Pindou 仓库点击 **Run pipeline**，选择 `main`，在 **Additional pipeline variables** 中新增变量名 `BUILD_TARGET`，填以下任一值：

- `web`：前端检查、测试和构建，附带共享部署配置检查；不启动 PostgreSQL。
- `api`：后端检查和测试、临时 PostgreSQL 检查，以及共享部署配置检查；不运行 Web。
- `postgresql`：仅验证临时 PostgreSQL 的就绪、版本、SQL 读写与事务回滚；不下载源码，不运行前后端或部署配置检查。
- `all`：全部检查。未填或空值也默认全部。

变量区分大小写，非法值会使参数校验失败。更换目标需新建流水线，重试旧任务会沿用原变量。这里使用附加变量输入，不是原生下拉菜单。

PostgreSQL 使用官方 `postgres:17-alpine` 临时服务，不构建数据库镜像，不操作 NAS 现有数据库，不发布或部署生产服务。自动 push 仍按原路径条件选择任务，不由手动变量覆盖。
