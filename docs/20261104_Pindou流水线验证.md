## 流水线范围

- 仅响应该分支的 manual/push 事件，不构建其他分支或外部 PR。
- API：Python 3.12、Ruff、pytest，使用临时 PostgreSQL 验证数据库并发测试；普通测试仍由原有 fixture 隔离 SQLite、文件及外部服务。
- Web：Node 22、pnpm 11.10.0、锁文件安装、ESLint、Vitest、TypeScript、Next.js webpack 生产构建，路径为 `/app/pindou`，检查 standalone 入口。
- 不发布镜像或部署应用，不接入 NAS 上现有拼豆数据库、卷或服务。任务资源沿用 Agent 的每容器 2 CPU / 1.5 GiB 限额。

## 网络适配

NAS 使用仓库原部署 Dockerfile 同源的 Node/Python 基础镜像，已实际拉取成功。普通 Git clone 能查询分支但 pack 传输持续停滞；初始配置失败已修正，停滞的测试任务已取消。

最终 checkout 改用当前可达的 GitHub Git Data API：下载指定 CI commit 的完整文件树，逐个校验 blob 的 Git SHA-1，拒绝危险路径、子模块、符号链接及截断文件树，保留执行权限，不创建 `.git`。API token 复用已由用户授权的 Woodpecker GitHub OAuth token，以仓库 Secret 保存，仅用于 manual/push，不进入源码或日志。

自动 push 触发仍依赖另行解决的 FN Connect Webhook 入口，本次主动通过手动任务验证。
